❓ LiliCorpus 使用说明

🔍 搜索

  • 在搜索框输入关键词，按 Enter 或点击按钮搜索
  • 多个关键词用空格分隔，默认为 AND（同时包含所有词）
  • 排除词前加 -，例如 攻撃 -魔法：含「攻撃」但不含「魔法」
  • 勾选「区分大小写」后，英文字母大小写视为不同
  • 搜索结果上限 500 条，结果过多时请增加关键词缩小范围

🎮 数据浏览

  • 顶部 Tab 可切换「💬 剧情台词库」和「⚔️ 游戏技能库」两个独立数据库
  • 点击游戏标签按钮只看该游戏的条目，再次点击取消筛选
  • 技能条目右侧的「展开上下文」可查看相邻词条

⭐ 收藏夹

  • 点击条目右侧的 ☆ 可收藏，收藏结果跨会话保留在本浏览器
  • 点击「⭐ 收藏夹」标签可查看所有已收藏条目
收藏数据存储在本地（localStorage），清除浏览器数据会丢失。

🔗 网址抓取（临时扩充技能库）

  • 在「粘贴网址自动抓取」区域输入攻略页面网址，自动识别技能表格
  • 支持 kamigame.jp、gamerch.com、altema.jp、gamewith.jp 等常见攻略站
  • 抓取结果仅在本次浏览器会话内可搜索，刷新页面后丢失
  • 抓取通过 CORS 代理转发，偶尔较慢或失败，换个代理或稍后重试

💾 永久保存到数据库

  • 配置 GitHub Fine-grained Token 后，点击「保存到数据库」直接写入仓库
  • 几分钟后 GitHub Actions 自动重建，数据对所有用户生效
  • 未配置 Token 可点击「导出 JSONL」，将文件发给维护者手动提交
